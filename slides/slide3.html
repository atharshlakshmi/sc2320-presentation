Proof of Ω(n): From Deterministic to Randomized

Reducing the problem through counting and Yao's minimax

1

Proposition 5: No monotone classifier is optimal for both P−1(i) and P+1(i).

An optimal classifier must know if the anomaly pair is (−1) or (+1) — so the algorithm must find and identify it.

↓
2

Free labels boost: Strengthen the algorithm — probing one element in a pair reveals both labels for free.

If the lower bound holds even with this advantage, it holds without it too.

↓
3

Deterministic counting (Lemma 11): Adet probes pairs x1, x2, ..., xt in sequence, stops when anomaly found.

If Adet errs on ≤ cn/2 inputs, it probes ≥ n(1−c)/2 pairs, giving family-cost ≥ n²(1−c²)/4.

↓
4

Yao's minimax → Corollary 12: Any randomized algorithm with family-err < n/3 has E[family-cost] = Ω(n²).

Since there are n inputs, at least one input requires Ω(n) expected probes.
