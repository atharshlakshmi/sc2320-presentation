Theorem 13 — Even a c-approximate answer needs Ω(w · Log(n / k*w)) probes

Theorem 13

For any constant c ≥ 1, any algorithm guaranteeing expected error ≤ c·k* must probe Ω(w′ · Log(n′/w′)) elements in expectation on some input with width w and optimal error k*.

Construction: Boxes + Dummy Points

Key Idea: Dummy Points Force Correctness

Each non-dummy point is surrounded by ck dummy points with matching labels. If the algorithm misclassifies any non-dummy point, it misclassifies ≥ ck+1 points, violating the c·k* error guarantee.

Reduction to Realizable Case

Since the algorithm must correctly classify all non-dummy points, it effectively solves the realizable problem on the original point set ⇒ inherits the Ω(w′ Log(n′/w′)) lower bound.
