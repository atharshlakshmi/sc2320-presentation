Recap: What We Know So Far

The upper bounds leave a question — are they tight?

RPE Algorithm (Thm 1)

Upper Bound

Expected error ≤ 2k*

Expected cost: O(w · Log(n/w))

  • Simple random-probe-and-eliminate
  • Approximation ratio 2 is tight for RPE
  • Optimal when k* ≤ (n/w)1−δ

Coreset Algorithm (Thm 6)

Upper Bound

Error ≤ (1+ε)k* w.h.p.

Cost: O(w/ε² · Log(n/w) · log n)

  • Relative-comparison coreset technique
  • Works for any ε > 0
  • Uses the "unknown Δ" trick

The Key Question

Can we do better than these costs? Or are these algorithms near-optimal?

We need lower bounds to answer this.
