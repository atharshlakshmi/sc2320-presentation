Theorem 14 — Any algorithm needs Ω(w/ε²) probes

Theorem 14

For 0 < ε ≤ 1/10, any algorithm guaranteeing expected error (1+ε)k* must probe Ω(w/ε²) elements in expectation on some input of width w. Holds even in d = 2.

Hard Input Construction

Place n/w points at each of w locations x1,...,xw (no dominance between locations). Each location gets a random bias:

μ1
x1
μ2
x2
μ1
x3
...
μ2
xw

μ1 = (1−γ)/2   slightly below 1/2

μ2 = (1+γ)/2   slightly above 1/2

where γ = 9ε. Each label is +1 with probability μ[i], independently.

Core difficulty: Distinguishing μ1 from μ2 at each location requires M = Θ(1/ε²) samples (by Le Cam / Anthony-Bartlett).

With w locations and budget < wM/8, more than half remain "unresolved".
