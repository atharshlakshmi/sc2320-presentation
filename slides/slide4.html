Lemma 11: The Counting Argument

If a deterministic algorithm errs on few inputs, it must probe many pairs

Adet probes a fixed sequence of pairs: x1, x2, ..., xt. It stops when it hits the anomaly pair, or outputs a fixed classifier hdet after all t probes.

Cost Accounting

Input type Anomaly pair i is... Probes used
i ∉ {x1,...,xt} Never found t probes each
i = xj Found at position j j probes
Errors

For each i ∉ {x1,...,xt}: hdet must fail on P−1(i) or P+1(i)  ⇒  family-err ≥ n/2 − t

↓
Total cost

family-cost = 2t(n/2 − t) + 2∑j=1..t j = nt − t² + t

↓
Constraint

family-err ≤ cn/2  ⇒  t ≥ n(1−c)/2

↓

For t ∈ [n(1−c)/2,  n/2]:   family-cost ≥ nt − t² ≥ n²(1−c²)/4
