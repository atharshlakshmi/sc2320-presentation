\section{Background and Motivation}
% ============================================================
\subsection{The Challenge of Entity Matching}
\begin{definition}[Entity Matching]
  Given two sets of entities  $E_1$  and $E_2$, the task is to determine, for every pair $(e_1, e_2) \in E_1 \times E_2$, whether $e_1$ and $e_2$ refer to the same real-world entity. It is a binary classification task that determines whether a candidate pair is a match $(+1)$ or non-match $(-1)$ \cite{tao21}.
\end{definition}

To motivate the problem, consider the following scenario where we have two sets of \texttt{entities} that we refer to here as product listings - $E_1$ and $E_2$, sourced from two different e-commerce platforms --- say Shopee and Lazada respectively. Each listing carries attributes such as \texttt{p-name}, \texttt{p-description}, \texttt{p-year}, and \texttt{p-price}. The goal of Entity Matching in this scenario is to decide, for every pair $(e_1, e_2) \in E_1 \times E_2$, if they are referring to the same real-world product. 

What makes this non-trivial is that even a genuinely matching pair may disagree on attribute values. For instance, one platform may list a product as \textit{``Sony WH-1000XM5''} while another lists it as \textit{``Sony Noise Cancelling Headphones XM5 Series''}. They are referring to the same product but with different representations. It is therefore insufficient to rely solely on attribute-level comparison to determine a match. To attain maximum accuracy in entity matching, it falls upon a human expert to manually inspect each pair and make a verdict. However, with thousands of listings on each platform, the number of pairs in $E_1 \times E_2$ grows quadratically - making manual inspection labor intensive and expensive. This motivates the need for a more systematic and efficient approach to Entity Matching.
% \subsubsection{}

\subsection{The Entity Resolution (ER) Pipeline}
% Overview of the pipeline stages:
%   Preprocessing → Blocking (mention LSH) → Comparison → Matching
% Flag Matching as the main focus of the paper.
To address the Entity Matching Problem, we transform it into a classification problem. This is done by passing datasets through an ER Pipeline consisting of three key steps: \textbf{Blocking}, \textbf{Comparison}, and \textbf{Matching}.  The first two steps serve as preprocessing stages that progressively reduce and structure the problem, while the third step is what Entity Matching entails and is the primary focus of the paper. We will go over the first two steps in brief before diving into greater detail on the third.

\subsubsection{Blocking}
As mentioned earlier in 1.1, the two entity sets $E_1$ and $E_2$ can grow quadratically, making it computationally infeasible to compare every pair. The goal of blocking is to narrow the search space down to a smaller candidate subset $S \subseteq E_1 \times E_2$, retaining only pairs that are plausible matches based on an application-dependent heuristic.

Going back to the Shopee-Lazada example, one may restrict $S$ to only those pairs $(e_1, e_2)$ where \texttt{p-year} agrees across both listings. Note that blocking is optional --- if skipped, $S = E_1 \times E_2$.
\newpage
\begin{remark}[Application-Dependent Heuristic]

\begin{sloppypar}
The criterion used for blocking is \textbf{application-dependent}; there is no universal rule for what constitutes an ``obvious non-match''.
\end{sloppypar}
  For example:
  \begin{itemize}
    \item \textbf{E-commerce:} A mismatched \texttt{p-year} is a reliable signal to discard a pair.
    \item \textbf{Hospital records:} Mismatched blood type might serve that role.
    \item \textbf{Legal documents:} Neither attribute would reliably apply.
  \end{itemize}
  The heuristic is therefore dictated by which attributes are reliable and meaningful in the specific domain.

  A notable example of a more general, domain-agnostic blocking heuristic is
  \textbf{Locality Sensitive Hashing (LSH)}. It groups similar pairs into candidate buckets based on hash collisions, this was covered in Chapter 3 of this course.
\end{remark}

\subsubsection{Comparison}
For each remaining pair $(e_1, e_2) \in S$, the comparison step quantifies their similarity across $d$ attributes using a set of similarity functions $sim_1, sim_2, \ldots, sim_d$. The $i$-th coordinate of the resulting point $p_{e_1,e_2}$ equals $sim_i(e_1, e_2)$, where a higher value indicates greater similarity on that attribute. The choice of similarity function depends on the attribute type:
\begin{itemize}
  \item For numerical attributes such as \texttt{p-price}, one may use $-|e_1.\texttt{price} - e_2.\texttt{price}|$, where the negation ensures consistency with the convention that higher values reflect greater similarity. 
  \item For text attributes such as \texttt{p-name} and \texttt{p-description}, functions such as edit distance, Jaccard similarity, or cosine similarity may be employed. 
\end{itemize}

\begin{example}
  Consider an entity pair $(e_1, e_2) \in S$. $e_1$ is a Shopee listing and $e_2$ is a Lazada listing for what may be the same product. Suppose each entity has the attributes \texttt{p-name}, \texttt{p-description}, \texttt{p-year}, and \texttt{p-price}. We pass each attribute pair into a pre-defined similarity function as follows:
  \begin{itemize}
    \item \texttt{p-name}: a text attribute --- use Jaccard similarity. E.g., \textit{``Sony WH-1000XM5''} vs \textit{``Sony Noise Cancelling XM5''} $\rightarrow$ $sim_1(e_1, e_2) = 0.8$
    
    \item \texttt{p-description}: a long text attribute --- use cosine similarity. $\rightarrow$ $sim_2(e_1, e_2) = 0.65$
    
    \item \texttt{p-year}: a numerical attribute --- use exact match, returning 1 if equal and 0 otherwise. $\rightarrow$ $sim_3(e_1, e_2) = 1$
    
    \item \texttt{p-price}: a numerical attribute --- use $-|e_1.\texttt{price} - e_2.\texttt{price}|$. E.g., \$350 vs \$345 $\rightarrow$ $sim_4(e_1, e_2) = -5$
  \end{itemize}

  The resulting point representing this pair in $\mathbb{R}^4$ is: $$p_{e_1, e_2} = (0.8,\ 0.65,\ 1,\ -5)$$

  This will be done for every pair in $S$.
\end{example}

This process yields a $d$-dimensional set of points $P = \{p_{e_1,e_2} \mid (e_1, e_2) \in S\}$ which is handed over to the Matching step.

\subsubsection{Matching}
The entity matching objective now becomes a binary classification task of assigning each point $p_{e_1,e_2} \in P$ to its correct ground truth label, which is $+1$ for a matching pair and $-1$ otherwise. While the ultimate approach to this would be with human judgement, this paper introduces \textbf{Monotone Classification} as a way to automate the process while ensuring a high degree of labelling accuracy.
% The naive approach to this through human judgement, which can guarantee correctness but with the downside of becoming expensive as earlier mentioned. This paper proposes a more automated approach --- 

\subsection{Monotone Classification}
Instead of relying on human judgement, we want to find a classifier to correctly label matching and non-matching entities.

The input is the set $P$ of $n$ points in $\R^{d}$ for $d \geq 1$ that we obtained from the Comparison step. Each point $p \in P$ holds a label from $\{-1, 1\}$ which is represented as $label(p)$.

We first define a classifier as a function:
$$ h : \R^{d} \rightarrow \{-1, +1\}$$

where $h(p) = label(p)$ is a correct classification made by $h$ and will be a misclassification otherwise.

The question is, what would make a good classifier in this context?

\subsubsection{The Monotonicity Constraint}
To answer this, we first introduce the notion of \textbf{dominance}.
We say that a point $p \in \mathbb{R}^d$ \textit{dominates} another point $q \in \mathbb{R}^d$, written $p \succ q$, if:

$$p[i] \geq q[i] \quad \text{for all } i \in [d]$$

That is, $p$ scores at least as high as $q$ on every attribute. In the context of entity matching, this means that the pair represented by $p$ is at least as similar as the pair represented by $q$ on every feature.

This supports the \textbf{Monotonicity Constraint}. A classifier $h$ is said to be \textbf{monotone} if:

$$p \succ q \implies h(p) \geq h(q)$$
Intuitively, if a pair $p$ is at least as similar as $q$ on every attribute, it would be contradictory for $h$ to label $p$ as a non-match $(-1)$ while labeling $q$ as a match $(+1)$. A more similar pair should receive at least as positive a label. We denote the set of all monotone classifiers as $\mathbb{H}_{mon}$. So for entity matching, the key criteria of our classifier is that it must be \textbf{monotone}.

\subsubsection{The Optimal Monotone Error}
Given a classifier $h$, its \textbf{error} on $P$ is defined as the number of points it misclassifies:

$$err_P(h) = \sum_{p \in P} \mathbf{1}_{h(p) \neq label(p)}$$

That is, the total count of points in $P$ whose assigned label differs from their ground truth. A classifier $h \in \mathbb{H}_{mon}$ is said to be \textbf{optimal} on $P$ if it achieves the smallest possible error among all monotone classifiers. We define this minimum achievable error as the \textbf{Optimal Monotone Error}:

$$k^* = \min_{h \in \mathbb{H}_{mon}} err_P(h)$$

Note that $k^*$ need not be zero --- in practice, the labels in $P$ may not perfectly obey monotonicity due to noise in the data, meaning even the best monotone classifier will misclassify some points.

\begin{figure}[ht]
  \centering
  \includegraphics[width=0.5\textwidth]{../classification_example.png}
  \caption{Labelling of input set $P$ by monotone classifier $h$}
  \label{fig:classification-example}
\end{figure}
\begin{example}
  Consider the 2D point set $P$ illustrated in Figure 2 taken from Professor Tao's original paper \cite{tao21}. Each point $p_{e_1,e_2} \in P$ represents an entity pair with $d = 2$ similarity features. Black points carry label $+1$ (match) and white points carry label $-1$ (non-match).

  The monotone classifier $h$ that maps all black points to $+1$ except $p_1$, and all white points to $-1$ except $p_{11}$ and $p_{15}$, achieves $err_P(h) = 3$. No other monotone classifier does better on $P$, and hence $k^* = 3$. Note that $k^* > 0$ --- this is the non-realizable case, as no monotone classifier can perfectly separate all points in $P$.
\end{example}


We now want an algorithm $\mathcal{A}$ to find a classifier from $\mathbb{H}_{mon}$ with low error on $P$. Note that in the beginning, the labels on all points in $P$ are hidden. In order for $\mathcal{A}$ to gain better understanding in forming an optimal classifier, it is allowed to query an \emph{oracle} --- a human expert in practice -- to reveal the ground truth label of a chosen point $p \in P$. This action is defined as a \emph{probe}. To assess the efficiency of the $\mathcal{A}$, we can measure its cost by the number of \emph{probes} it makes.

To find an optimal monotone classifer on $P$, one can simply have $\mathcal{A}$ to probe all of $P$ with a cost of n. On the other hand, not probing at all would incur zero cost but the classifier may perform poorly on $P$. This presents us with the challenge of minimizing the number of probes while still producing a classifier with sufficiently low error.

Formally, given a tolerance parameter $\epsilon \geq 0$, the goal is to determine the minimum number of probes required to guarantee a classifier with error at most $(1 + \epsilon) \cdot k^*$. This is defined formally below.

\begin{problem}[Monotone Classification with Relative Precision Guarantees]\label{prob:main}
Given a real value $\epsilon \geq 0$, find a monotone classifier $h \in \mathbb{H}_{mon}$ whose error on $P$ is at most $(1 + \epsilon) \cdot k^*$, while minimizing the number of probes made by $\mathcal{A}$.
\end{problem}

Note that when $\epsilon = 0$, the algorithm must find an exactly optimal classifier, which as we will see requires $\Omega(n)$ probes in the worst case --- essentially probing all of $P$. This justifies the introduction of $\epsilon > 0$, where even a small tolerance dramatically reduces the probing cost. The remainder of this paper studies how efficiently this problem can be solved across the full range of $\epsilon$.

\subsection{Active Classification (Supplementary)}
To motivate Active Classification, we first revisit a familiar example of \textbf{passive classification} --- the \textbf{Perceptron Algorithm}, covered in SC2300 Machine Learning. Recall that the Perceptron is a mistake-driven algorithm that iterates through all training examples $S_n = \{(x^{(t)}, y^{(t)}), t = 1, \ldots, n\}$, where both the points \textit{and} their labels are fully visible from the start. It updates its parameter vector $\theta$ whenever a misclassification occurs, converging to a linear classifier that correctly separates all training examples --- provided they are linearly separable. This is the \textbf{realizable case}.

\begin{remark}[Realizable Case]
A classification problem is \textbf{realizable} if there exists a classifier $h \in \mathbb{H}_{mon}$ that correctly classifies all points in $P$ with zero error, i.e., $k^* = 0$. This is analogous to linear separability in the Perceptron setting.
\end{remark}

When data is not linearly separable, the Perceptron fails to converge --- motivating the use of \textbf{hinge loss} to tolerate a margin of error. The same challenge arises here: in practice, the labels in $P$ rarely obey monotonicity perfectly, meaning no monotone classifier can achieve zero error. This is the \textbf{non-realizable case}.

\begin{remark}[Non-Realizable Case]
A classification problem is \textbf{non-realizable} if no classifier $h \in \mathbb{H}_{mon}$ can achieve zero error on $P$, i.e., $k^* > 0$. This arises when the labels in $P$ contain noise --- points that violate monotonicity regardless of which classifier is chosen. This is analogous to the non-linearly separable case in SC2300.
\end{remark}

\begin{remark}
Just as hinge loss introduces a tolerance for misclassified 
points in the non-separable case, this paper introduces 
$(1+\epsilon)k^*$ as a multiplicative tolerance for the 
non-realizable case --- same philosophy, different context.
\end{remark}

In the context of Entity Matching, the non-realizable case is the norm. Furthermore, unlike the Perceptron, labels are \textbf{not} visible from the start --- they are hidden and can only be revealed through probing. This is where \textbf{Active Classification} comes in. Devise a learning strategy where the algorithm selectively chooses which points to probe rather than requiring all labels upfront, gathering just enough evidence to construct a classifier with error at most $(1+\epsilon)k^*$ while minimizing the number of probes. In other words, Active Classification takes into account cost apart from just accuracy. 

The contrast with passive classification is summarized below:

\begin{table}[h]
\centering
\begin{tabular}{lll}
\hline
 & \textbf{Passive (Perceptron)} & 
 \textbf{Active (This Paper)} \\
\hline
Labels & All visible from start & Hidden, revealed via probes \\
Setting & Realizable ($k^* = 0$) & Non-realizable ($k^* > 0$) \\
Cost metric & Number of iterations & Number of probes \\
Goal & Zero training error & $(1+\epsilon)k^*$ error \\
\hline
\end{tabular}
\caption{Passive vs.\ Active Classification}
\end{table}

A key limitation of existing active learning approaches is that they require prior knowledge of $k^*$ --- the optimal monotone error --- before the algorithm even begins. This is an unrealistic assumption in practice, since $k^*$ can only be determined after all labels are revealed. This paper proposes algorithms that require no such prior knowledge, working instead by strategically probing points to implicitly converge towards a $(1+\epsilon)$-approximate solution --- which we examine in the sections that follow.

\section{RPE Algorithm}
% ============================================================
Having formulated the problem in Section~\ref{prob:main}, we now turn to our first algorithm for solving it: the Random Probes with Elimination (RPE) algorithm. This algorithm is the paper's primary contribution for the realizable case ($k^*$=0) and serves as the foundation for the more general coreset-based approach in Section~\ref{sec:rcc}.

\subsection{The Algorithm}
% Describe Random Probes with Elimination (RPE): iterative random probing
% and elimination of elements via the monotonicity constraint.
RPE repeatedly performs two steps:
\begin{enumerate}
    \item Pick a random point and query its label
    \item Use monotonicity to eliminate all points whose labels are now determined
\end{enumerate}
\smallskip
\textbf{algorithm RPE(P):}
\[
\begin{array}{l}
\text{1. } Z = \emptyset \\
\text{2. } \textbf{while } P \neq \emptyset \textbf{ do} \\
\text{3. } \quad \text{probe an element } z \in P \text{ chosen uniformly at random and add } z \text{ to } Z \\
\text{4. } \quad \textbf{if } \text{label}(z) = 1 \textbf{ then remove from } P \text{ every } p \in P \text{ satisfying } p \succeq z \\
\text{5. } \quad \textbf{else remove from } P \text{ every } p \in P \text{ satisfying } z \succeq p \\
\qquad \text{/* note: } z \text{ is removed by Line 4 or 5 */} \\
\text{6. } \textbf{return } Z
\end{array}
\]

\begin{remark} [Intutition] If a point $z$ is positive, then every point above it must also be positive → remove them.
If $z$ is negative, then every point below it must also be negative → remove them.
Thus, each probe “wipes out” a whole region of points.
\end{remark}

The set $Z$ returned by RPE is the set of all probed points. The classifier produced from $Z$ is:

\[
h_{\text{RPE}}(p) = 
\begin{cases} 
 1 & \text{if } \exists z \in Z \text{ such that } \text{label}(z) = 1 \text{ and } p \succeq z, \\
 -1 & \text{otherwise}.
\end{cases}
\]

That is, a point $p$ is classified as positive if it lies above any known positive point; otherwise it is classified as negative. Thus, the algorithm only needs to remember:
“Where are the confirmed positive points?” 

\subsubsection*{Why is the Classifier always Monotone?} 
Suppose for contradiction that there exist points $p \succ q$ such that $h_{\text{RPE}}(p) = -1$ and $h_{\text{RPE}}(q) = 1$. Since $h_{\text{RPE}}(q) = 1$, there exists some $z \in Z$ with $\text{label}(z) = 1$ such that $q \succeq z$. But then $p \succ q \succeq z$, so $p \succeq z$ as well. By the definition of $h_{\text{RPE}}$, this implies $h_{\text{RPE}}(p) = 1$, contradicting the assumption that $h_{\text{RPE}}(p) = -1$.

\begin{remark}[Intuition]
If a point $q$ is labelled $+1$, it must dominate some positive probe $z$ in $Z$. If another point $p$ dominates $q$, then by transitivity ($p \succeq q \succeq z$), 
$p$ also dominates that same positive probe $z$ and must therefore also be $+1$.
\end{remark}

\subsection{Why It Works}
% Intuition and correctness argument behind the elimination strategy.
The efficiency of RPE stems from the fact that each probe does ``double duty''. When RPE probes a point $z$ and learns its label, monotonicity immediately determines the labels of an entire region points that are comparable to $z$.
\begin{itemize}
  \item If $\text{label}(z) = 1$: any point $p \succeq z$ is at least as similar as $z$ on every feature. Monotonicity forces $h(p) \ge h(z) = 1$, so all such $p$ must be labelled $+1$ and can be removed from $P$.
  \item If $\text{label}(z) = -1$: any point $p \preceq z$ is dominated by $z$, so monotonicity forces $h(p) \le h(z) = -1$. All such $p$ must be labelled $-1$ and are removed.
\end{itemize}

Only points whose label cannot yet be inferred by monotonicity remain in $P$ after each elimination step. These are the points the algorithm must still resolve, and it will probe them in subsequent iterations.

\subsection{A Worked Example: RPE in Action}
We trace RPE on the 2D point set $P$ from Figure~\ref{fig:classification-example}. Recall that black points have label $+1$ and white points have label $-1$. The optimal monotone classifier achieves $k^* = 3$ by misclassifying only $p_1, p_{11}, p_{15}$. The dominance width of this input is $w = 6$.

\begin{example}[from paper, Example 1.3]
Suppose RPE randomly probes $p_1$ first.
\begin{itemize}
  \item \textbf{Step 1:} Probe $p_1$. The oracle reveals $\text{label}(p_1) = 1$. RPE removes every $p \succeq p_1$. Since $p_1$ sits towards the bottom-left of the figure, it dominates (or equals) almost all other points. The entire $P$ is eliminated except $p_6, p_7, p_8$ (which lie below or incomparable to $p_1$).
  \item \textbf{Step 2:} Probe $p_8$. The oracle reveals $\text{label}(p_8) = -1$. RPE removes every $p \preceq p_8$, which eliminates $p_6, p_7$ and $p_8$ itself. $P$ is now empty. RPE terminates with $Z = \{p_1, p_8\}$.
  \item \textbf{Classifier output:} Since $\text{label}(p_1) = 1$, every point $p \succeq p_1$ is mapped to $+1$ by $h_{\text{RPE}}$. All other points (including $p_6, p_7, p_8$) are mapped to $-1$. 
  \item \textbf{Error:} $\text{err}_P(h_{\text{RPE}}) = 5$ (5 white points mapped to $+1$ due to dominating $p_1$).
\end{itemize}
\end{example}

This example demonstrates how a single probe of $p_1$ is enough to determine the labels of 13 out of 16 points. The cost of 2 probes is far below the naïve cost of $n = 16$. Note, however, that the error of $5$ exceeds $k^* = 3$ --- we will see why this is expected and bounded by the $2k^*$ guarantee.

\subsection{Guarantees}
% State the factor-of-2 approximation guarantee.
The following theorem (proved in full in the paper) captures the performance of RPE:
\begin{theorem}[RPE Guarantees]\label{thm:rpe}
For Problem~\ref{prob:main}, the RPE algorithm satisfies:
\begin{itemize}
  \item \textbf{Expected error:} The classifier $h_{\text{RPE}}$ has expected error at most $2k^*$:
  \[
    \mathbb{E}[\text{err}_P(h_{\text{RPE}})] \le 2k^*.
  \]
  \item \textbf{Expected cost:} RPE probes at most $O\bigl(w \cdot \log(n/w)\bigr)$ elements in expectation, where $w$ is the dominance width of $P$, $n = |P|$, and $\log(x) = \log_2(1+x)$.
\end{itemize}
\end{theorem}

Two aspects of this theorem are worth emphasizing. First, RPE never needs to compute $w$ --- the width is only used in the analysis. Second, when $k^* = 0$ (the realizable case), the expected error guarantee of $2k^* = 0$ means RPE always finds an optimal classifier.

\subsubsection*{Proof Sketch}

\subsubsection*{1. Error Analysis} 
Fix any monotone classifier $h \in \mathbb{H}_{\text{mon}}$. Call a point $p \in P$ \emph{$h$-good} if $h(p) = \text{label}(p)$ and \emph{$h$-bad} otherwise. The proof proceeds by induction on $|P|$, showing:
\begin{lemma}
  \item The number of \emph{$h$-good} elements misclassified by $h_{\text{RPE}}$ is at most $\text{err}_P(h)$ in expectation.
\end{lemma}
Setting $h = h^*$ (the optimal classifier), there are exactly $k^*$ $h^*$-bad elements. The total expected error is thus $\le k^* + k^* = 2k^*$.

\medskip
The central tool in the inductive argument is a \textbf{pairing between influence sets}. When RPE probes a point $z$, it may cause other points to be misclassified:
\begin{itemize}
    \item For an $h$-bad point $p$, $I_{\text{bad}}(p)$ is the set of $h$-good points that get forced into the wrong label if $p$ is probed first.
    \item For an $h$-good point $q$, $I_{\text{good}}(q)$ is the set of $h$-bad points that get forced into the correct label (according to $h$) if $q$ is probed first.
\end{itemize}

The key insight is that these influences balance perfectly:
\begin{lemma}
For any $h$-bad $p \in P$ and $h$-good $q \in P$,
$q \in I_{\text{bad}}(p) \iff p \in I_{\text{good}}(q)$.
Hence, $\sum_{p \in \text{bad}} |I_{\text{bad}}(p)| = \sum_{q \in \text{good}} |I_{\text{good}}(q)|$.
\end{lemma}

\textbf{Why does this give the $2k^*$ bound on the total expected error?} Because the total ``potential for error'' (left side) equals the total ``potential for correction'' (right side), the expected number of $h$-good points misclassified by RPE is bounded by the number of $h$-bad points ($k^*$). Adding the $k^*$ bad points themselves (which are always misclassified) yields:
\[
E[\text{err}_P(h_{\text{RPE}})] \le k^* + k^* = 2k^*.
\]

\begin{example}
  Let $P$ be the set of points in Figure~~\ref{fig:classification-example}, and $h$ be the classifier that maps all the black points to $1$ except $p_1$ and all the white points to $-1$ except $p_{11}$ and $p_{15}$. Thus, $p_1$, $p_{11}$, and $p_{15}$ are $h$-bad, while the other points of $P$ are $h$-good. The following are some representative influence sets:
\begin{itemize}
    \item $I_{\text{bad}}(p_{15}) = \{p_4, p_9, p_{10}, p_{12}, p_{13}, p_{14}, p_{16}\}$
    \item $I_{\text{bad}}(p_1) = \{p_2, p_3, p_5\}$
    \item $I_{\text{good}}(p_3) = \{p_1\}$
    \item $I_{\text{good}}(p_9) = \{p_{11}, p_{15}\}$
\end{itemize}
\end{example}

\subsubsection*{2. Cost Analysis} 
The efficiency of RPE is not measured by the total points $n$, but by the dominance width $w$ (the size of the largest set of incomparable points). The proof is summarized as follows:
\begin{enumerate}
  \item \textbf{Decomposition}: By Dilworth’s Theorem (Section~\ref{sec:chains}), any point set $P$ can be partitioned into $w$ disjoint chains (where every point in a chain is comparable to the others).
  \item \textbf{Parallel Search}: RPE effectively performs a randomized search on all $w$ chains simultaneously. Each probe in $P$ is guaranteed to land in one of these chains.
  \item \textbf{A\&E Game}: Within any single chain, RPE's behavior mimics an ``Attrition-and-Elimination'' game (Section~\ref{sec:ae}). Even if an adversary removes points to try and trick the algorithm, a random probe is likely to ``hit'' near the middle of the remaining chain, eliminating half of it.
\end{enumerate}
By summing the expected probes across $w$ chains and applying the concavity of the logarithm (Jensen's Inequality), we arrive at the total expected cost: $O\bigl(w \log \frac{n}{w}\bigr)$.

\subsection{Another Worked Example: Why the Factor of 2 Is Tight}

The error guarantee of $2k^*$ is the \emph{best possible} approximation ratio for RPE. The following example demonstrates this:

\begin{example}\label{ex:tight}
Consider Figure~\ref{fig:tightRPE}, where a point set $P$ in $\mathbb{R}^2$ contains one black point (label $+1$) and $n-1$ white points (label $-1$).

\textbf{Optimal error:} The monotone classifier that maps all points to $-1$ misclassifies only the black point, so $k^* = 1$.

\textbf{RPE's expected error:} With probability $1/n$, RPE probes the black point first. Since it has label $+1$ and dominates nothing, no points are eliminated. So, all $n-1$ white points remain and are later mapped to $+1$ by $h_{\text{RPE}}$, giving error $n-1$. With probability $1 - 1/n$, RPE probes a white point first, eliminates all dominated points (just itself), and the resulting error is $1$. Thus:
\[
\mathbb{E}[\text{err}(h_{\text{RPE}})] = \frac{1}{n}(n-1) + \left(1 - \frac{1}{n}\right)(1) = 2 - \frac{2}{n} \to 2 \quad \text{as } n \to \infty.
\]
Since $k^* = 1$, the approximation ratio approaches $2k^*/k^* = 2$. The factor of $2$ is therefore \emph{asymptotically tight} for RPE.
\end{example}

  \caption{The approximation ratio 2 is tight for RPE.}
  \label{fig:tightRPE}
\end{figure}

\subsection{Limitations}
% Discuss where RPE falls short (e.g.\ dependence on width w).
RPE has two key limitations:
\begin{enumerate}
  \item \textbf{The factor-of-2 error is tight.} As shown in Example~\ref{ex:tight}, no modification to RPE's random-probing strategy can reduce the approximation ratio below $2$. To achieve a ratio of $1+\epsilon$ for arbitrary $\epsilon > 0$, a fundamentally different technique is needed. This is the motivation for the \emph{relative-comparison coreset} approach in Section~\ref{sec:rcc}.
  \item \textbf{No high-probability guarantee.} Theorem~\ref{thm:rpe} gives an \emph{expected} error bound. In a single run, RPE may produce an error much larger than $2k^*$, as the bad scenario in Example~\ref{ex:tight} illustrates. The coreset-based algorithm upgrades this to a \emph{w.h.p.} guarantee at the cost of an extra $O(\log n / \epsilon^2)$ factor in probes.
\end{enumerate}

\subsection{Chains, Dilworth's Theorem, and the A\&E Game (Supplementary)}

\emph{This section covers supplementary material relevant to the cost analysis.}

\subsubsection{Chains and Dilworth's Theorem\label{sec:chains}} 
A \emph{chain} is a subset $S \subseteq P$ where every two elements are comparable under dominance: we can order them as $p_1 \preceq p_2 \preceq \dots \preceq p_{|S|}$. A \emph{chain decomposition} partitions $P$ into disjoint chains. Dilworth's theorem~\cite{dilworth50} guarantees the existence of a chain decomposition using exactly $w$ chains (where $w$ is the width of $P$).

\begin{example}
The input $P$ in Figure~\ref{fig:classification-example} can be decomposed into $6$ chains:
\begin{itemize}
    \item $C_1 = \{p_1, p_2, p_3, p_4, p_{10}\}$
    \item $C_2 = \{p_{11}\}$
    \item $C_3 = \{p_5, p_9, p_{12}\}$
    \item $C_4 = \{p_{16}\}$
    \item $C_5 = \{p_{13}\}$
    \item $C_6 = \{p_6, p_7, p_8, p_{14}, p_{15}\}$
\end{itemize}
The points $p_{10}, p_{11}, p_{12}, p_{16}, p_{13}, p_{14}$ indicate the absence of any chain decomposition of $P$ having less than $6$ chains.
\end{example}

\subsubsection{A\&E Game\label{sec:ae}} 
To analyze RPE's cost within a single chain, the paper introduces a two-player \emph{Attrition-and-Elimination (A\&E) game} on a chain $C$ of $m$ points. In each round:
\begin{itemize}
  \item Bob (adversary) may delete any subset of points from $C$ (attrition).
  \item Alice picks a uniformly random point $p \in C$ and deletes all points $q \succeq p$ (elimination).
\end{itemize}
The game ends when $C$ is empty. This generalizes a \textbf{random binary search}: while a standard binary search assumes the points stay put, the A\&E game proves that even if an adversary removes points to ``hide'' the middle, Alice will still finish quickly.

\begin{lemma}Regardless of Bob's strategy, the expected number of rounds $Y$ satisfies $\mathbb{E}[Y] = O(\log m)$.
\end{lemma}

\noindent The proof proceeds in two steps: showing that each round has a high probability of being ``successful,'' and then bounding the total rounds needed.

\medskip
\noindent \textbf{1. Probability of a ``Successful'' Round:} 
Define a round as \emph{successful} if it reduces the number of elements in the chain by at least a factor of $2$. 
\begin{itemize}
    \item Let $m'$ be the number of points left after Bob's attrition in a round. 
    \item Let the points be ordered $p_1 \preceq p_2 \preceq \dots \preceq p_{m'}$. 
    \item If Alice picks any point $p_i$ where $i \le \frac{m'}{2} + 1$, then at most half the points remain after she eliminates everything dominating $p_i$.
    \item Since Alice picks uniformly at random, the probability of picking such a point is $> 1/2$. Thus, every round is successful with probability $> 1/2$, regardless of what Bob does.
\end{itemize}

\medskip
\noindent \textbf{2. Total Expected Rounds:}
A chain of size $m$ can only be halved $\log_2(m)$ times before it is empty. Therefore, we only need $\log_2(m)$ ``successful'' rounds to end the game. 
\begin{itemize}
    \item If we run $Y = 2\log_2(m)$ rounds, we expect half of them to be successful (which would be exactly $\log_2(m)$).
    \item Using the properties of independent trials, the probability that we fail to reach $\log_2(m)$ successes in $2\log_2(m)$ rounds is very small (less than $1/m$).
    \item Even in the worst-case scenario where we never get enough successes, the game must end in at most $m$ rounds (since Alice removes at least one point per round).
\end{itemize}

Combining these, the expected number of rounds is dominated by the $2\log_2(m)$ term:
\[
\mathbb{E}[Y] \le 2\log_2(m) + m \cdot \Pr(\text{failure}) = O(\log m).
\]

\section{Relative-Comparison Coresets (RCC)}\label{sec:rcc}
% ============================================================
 
\subsection{Why RPE Isn't Enough}

Recall that RPE achieves an expected error of at most $2\kstar$, and this guarantee is tight. In the entity-matching context a factor-2 margin may be unacceptable for a production pipeline. 

The goal of this section is to achieve an approximation ratio of $(1+\varepsilon)$ for any user-specified $\varepsilon>0$: find a function $F:\Hmon\to\R$ such that
\[
  F(h)\le F(h') \;\implies\; \mathrm{err}_P(h)\le(1+\varepsilon)\,\mathrm{err}_P(h').
\]
Since $F(\hat h)\le F(h^*)$ for any optimal $h^*$, this gives $\mathrm{err}_P(\hat h)\le(1+\varepsilon)\kstar$.

\begin{remark}[Why estimating $\mathrm{err}_P(h)$ directly fails]
A natural idea is to set $F(h)=\mathrm{err}_P(h)$ estimated by probing. But even for $h^{pos}$ (the all-$+1$ classifier), estimating its error to within a constant relative factor requires finding the single $-1$ element (or confirming none exists), which demands $\Omega(n)$ probes in expectation.
\end{remark}
 
% ─────────────────────────────────────────────────────────────
\subsection{The Unknown-$\Delta$ Technique}

We sidestep the $\Omega(n)$ barrier by constructing $F$ satisfying a weaker condition. Instead of estimating $\mathrm{err}_P(h)$ exactly, we find an $F$ where all estimates are shifted by the same unknown constant $\Delta$:
 
\begin{equation}\label{eq:Fprop}
  \mathrm{err}_P(h)\!\left(1 - \tfrac{\varepsilon}{4}\right) + \Delta \;\le\; F(h) \;\le\; \mathrm{err}_P(h)\!\left(1 + \tfrac{\varepsilon}{4}\right) + \Delta \qquad \forall\, h \in \Hmon,
\end{equation}
 
 
\begin{proposition}\label{prop:Fimplies}
  Any $F$ satisfying \eqref{eq:Fprop} has the relative $\varepsilon$-comparison property.
\end{proposition}
 
\begin{proof}
  Suppose $F(h) \le F(h')$. Using the left inequality of \eqref{eq:Fprop} for $h$ and the right for $h'$, then cancelling $\Delta$:
  \begin{align*}
    \mathrm{err}_P(h)\!\left(1 - \tfrac{\varepsilon}{4}\right)
    &\;\le\; F(h) - \Delta \;\le\; F(h') - \Delta \;\le\; \mathrm{err}_P(h')\!\left(1 + \tfrac{\varepsilon}{4}\right).
  \end{align*}
  Rearranging:
  \[
    \mathrm{err}_P(h) \;\le\; \frac{1 + \varepsilon/4}{1 - \varepsilon/4}\,\mathrm{err}_P(h') \;\le\; (1+\varepsilon)\,\mathrm{err}_P(h'),
  \]
  where the last step uses $\frac{1+\varepsilon/4}{1-\varepsilon/4} \le 1+\varepsilon$ for all $\varepsilon \in (0,1]$.
\end{proof}
 
The key insight: $\Delta$ cancels whenever we \emph{compare} two classifiers. We never need to know its value — only its existence.

\subsubsection{Running Example} 
We will trace a small 1D instance through the entire construction. Let $P = \{1, 2, 3, 4, 5, 6, 7, 8\}$ with labels
\[
  \underbrace{-1, -1, -1, -1}_{\text{points } 1\text{--}4},\; \underbrace{+1, +1, +1, +1}_{\text{points } 5\text{--}8}.
\]
Every monotone 1D classifier has the form $h^\tau(p) = +1$ iff $p > \tau$. The optimal classifier is $h_{4.5}$, with $\kstar = 0$. We set $\varepsilon = 1/2$.

% ─────────────────────────────────────────────────────────────
\subsection{The Coreset Technique}

We realise $F$ via a \textbf{relative-comparison coreset}: a weighted subset $Z \subseteq P$ whose weighted error $\mathrm{w\text{-}err}_Z(h)$ satisfies \eqref{eq:Fprop} for all $h$.
 
\begin{definition}[Relative-Comparison Coreset]
  A \textbf{relative-comparison coreset} of $P$ is a subset $Z \subseteq P$ where every $z \in Z$ has its label revealed and carries a positive weight $\mathrm{weight}(z)$, such that the \emph{weighted error}
  \[
    \mathrm{w\text{-}err}_Z(h) \;:=\; \sum_{z \in Z : h(z) \ne \mathrm{label}(z)} \mathrm{weight}(z)
  \]
  satisfies \eqref{eq:Fprop} for every $h \in \Hmon$ --- i.e., $\mathrm{w\text{-}err}_Z$ serves as the desired function $F$.
\end{definition}
 
The novelty of the unknown-$\Delta$ approach is that classical coresets approximate $\mathrm{err}_P(h)$ itself (costing $\Omega(n)$ probes), whereas here $\Delta$ never needs to be computed.

% ─────────────────────────────────────────────────────────────
\subsection{Building the Coreset in 1D: The Recursive Framework}
 
The 1D construction works by solving the following problem at every level of recursion. The coreset is built by the algorithm \textsc{BuildCoreset}, which solves Problem~\ref{prob:two} recursively.
 
\begin{problem}[1D Function Approximation]\label{prob:two}
  Let $P$ be a multiset of 1D labeled points (as in Problem~\ref{prob:main} with $d=1$), and $\varepsilon \in (0,1]$. Find a function $F : \Hmon \to \R$ such that every $h \in \Hmon$ satisfies simultaneously:
  \begin{align}
    |F(h) - \mathrm{err}_P(h)| &\;\le\; \varepsilon|P|/64, \label{eq:p2abs}\\
    \mathrm{err}_P(h)\!\left(1-\tfrac{\varepsilon}{4}\right) + \Delta &\;\le\; F(h) \;\le\; \mathrm{err}_P(h)\!\left(1+\tfrac{\varepsilon}{4}\right) + \Delta, \label{eq:p2rel}
  \end{align}
  for some (possibly unknown) $\Delta$ with $|\Delta| \le \varepsilon|P|/64$.
\end{problem}
 

\subsubsection{Estimating Error via Sampling (Functions $G_1$, $G_2$, $F_\alpha$)}
At each recursion level on a set $Q \subseteq P$, we draw a uniform sample $S$ of size $O\!\left(\frac{1}{\varepsilon^2}\log\frac{|Q|\,\ell}{\delta}\right)$ from $Q$, where $\ell = O(\log n)$ is the number of recursion levels. Define
\[
  G(h) \;:=\; \frac{|Q|}{|S|}\cdot \mathrm{err}_S(h).
\]
By a standard concentration bound, $G$ satisfies condition~\eqref{eq:p2abs} for $Q$ simultaneously for all $h \in \Hmon$, with high probability. Three such estimates are used per level:
\begin{itemize}
  \item $G_1$, sampled from the full $P$, is used to \emph{locate the split point}. Does not enter the coreset.
  \item $G_2$, sampled from $P_{\mathrm{rest}}$, approximates $\mathrm{err}_{P_{\mathrm{rest}}}(h)$ and contributes its sampled points to $Z$.
  \item $F_\alpha$, sampled from $P_\alpha$, approximates $\mathrm{err}_{P_\alpha}(h)$ and contributes its sampled points to $Z$.
\end{itemize}

Together, the target function for Problem~\ref{prob:two}, 
\[
F(h) = G_2(h) + F_\alpha(h) + F_{\mathrm{mid}}(h)
\]
where $F_{\mathrm{mid}}$ comes from recursion on $P_{\mathrm{mid}}$ satisfies both conditions of Problem~\ref{prob:two} for the full $P$.

\medskip
As there are $\ell$ levels, the overall cost is $O\!\left(\frac{\ell}{\epsilon^2} \log \frac{n}{\delta}\right) = O\!\left(\frac{\log n}{\epsilon^2} \cdot \log \frac{n}{\delta}\right)$, which lets us sovle Problem~\ref{prob:two} with a probability of at least $1 - \delta$.

\subsubsection{Example (continued)}
\begin{itemize}
  \item Suppose at the top level we draw $S_1 = \{2, 5, 7\}$ from $P$, with labels $-1, +1, +1$.
  \item For $h_{4.5}$ (optimal): $\mathrm{err}_{S_1}(h_{4.5}) = 0$, so $G_1(h_{4.5}) = 0$. True error is also $0$; condition~\eqref{eq:p2abs} holds trivially ($|0 - 0| = 0 \le 0.0625$).
  \item For $h_{2.5}$: $\mathrm{err}_{S_1}(h_{2.5}) = 1$ (point 5 misclassified), so $G_1(h_{2.5}) = 8/3 \approx 2.67$. True error is $2$; the gap is $0.67$, well within the tolerance $\varepsilon|P|/64 = 0.0625 \cdot 8 = 0.5$... close to the boundary, illustrating why the sample size matters.
\end{itemize}
\noindent  
 
\subsubsection{Splitting $P$ into Three Parts}
 
The purpose of $G_1$ --- satisfying condition~\eqref{eq:p2abs} for the full $P$ --- is to identify where the error function transitions through the value $|P|/4$. Concretely, define:
\begin{align*}
  \alpha &= \text{smallest } \tau \in P \cup \{-\infty\} \text{ with } G_1(h^\tau) < |P|\!\left(\tfrac{1}{4} - \tfrac{\varepsilon}{64}\right),\\
  \beta &= \text{largest } \tau \in P \cup \{-\infty\} \text{ with } G_1(h^\tau) < |P|\!\left(\tfrac{1}{4} - \tfrac{\varepsilon}{64}\right).
\end{align*}
Because $G_1$ satisfies~\eqref{eq:p2abs}, any $h^\tau$ with $G_1(h^\tau)$ below this threshold has $\mathrm{err}_P(h^\tau) < |P|/4$. This splits $P$ into:
\[
  P_\alpha = \{p \in P : p = \alpha\}, \quad P_{\mathrm{mid}} = \{p \in P : \alpha < p \le \beta\}, \quad P_{\mathrm{rest}} = P \setminus (P_\alpha \cup P_{\mathrm{mid}}).
\]
 
Crucially, classifiers $h^\tau$ with $\tau \notin [\alpha, \beta)$ have $\mathrm{err}_P(h^\tau) \ge |P|/4$, so condition~\eqref{eq:p2rel} for those classifiers follows from~\eqref{eq:p2abs} alone (with $\Delta = 0$). The recursive step only needs to handle $\tau \in [\alpha, \beta)$, where errors are small and the unknown $\Delta$ is needed.
 
\begin{proposition}[Size of $P_{\mathrm{mid}}$]\label{prop:midsize}
  $|P_{\mathrm{mid}}| < |P|/2$.
\end{proposition}
 
\begin{proof}
  If $\alpha = \beta = \mathrm{null}$, the claim is trivial. Otherwise, $P_{\mathrm{mid}}$ cannot contain $\ge |P|/4$ positive-label points (else $G_1(h_\beta) \ge |P|(1/4 - \varepsilon/64)$, contradicting the definition of $\beta$). By a symmetric argument, it cannot contain $\ge |P|/4$ negative-label points either. Hence $|P_{\mathrm{mid}}| < |P|/2$.
\end{proof}
 
Proposition~\ref{prop:midsize} guarantees the recursion terminates in $O(\log n)$ levels.
\subsubsection{Example (continued)}
With $|P| = 8$ and $\varepsilon = 1/2$, the threshold is $8(1/4 - 1/128) \approx 1.94$. Suppose $G_1$ evaluates to roughly:
 
\begin{center}
\begin{tabular}{lcc}
  \toprule
  Classifier $h^\tau$ & True $\mathrm{err}_P(h^\tau)$ & $G_1(h^\tau)$ (approx.) \\
  \midrule
  $h_{-\infty}$ (all $+1$) & 4 & 4.0 \\
  $h_{1}$ & 3 & 3.2 \\
  $h_{2}$ & 2 & 2.1 \\
  $h_{3}$ & 1 & 1.2 \\

$G_1$ drops below 1.94 at $\tau = 3$ and $\tau = 4$. So $\alpha = 3$, $\beta = 4$, giving:
\[
  P_\alpha = \{3\}, \quad P_{\mathrm{mid}} = \{4\}, \quad P_{\mathrm{rest}} = \{1, 2, 5, 6, 7, 8\}.
\]
Note $|P_{\mathrm{mid}}| = 1 < 4 = |P|/2$, consistent with Proposition~\ref{prop:midsize}.
 
\subsubsection{Assembling the Coreset $Z$}
 
The coreset is assembled level by level:
\begin{itemize}
  \item A sample $S_2$ drawn from $P_{\mathrm{rest}}$ enters $Z$ with weight $|P_{\mathrm{rest}}|/|S_2|$.
  \item A sample $S_\alpha$ drawn from $P_\alpha$ enters $Z$ with weight $|P_\alpha|/|S_\alpha|$.
  \item The recursion on $P_{\mathrm{mid}}$ returns a sub-coreset $Z_{\mathrm{mid}}$, which is also included in $Z$.
\end{itemize}
Setting $F(h) = G_2(h) + F_\alpha(h) + F_{\mathrm{mid}}(h)$ and $\Delta = \Delta_\alpha + \Delta_{\mathrm{mid}} + (G_2(h_\beta) - \mathrm{err}_{P_{\mathrm{rest}}}(h_\beta))$, one can verify (see Section~3 of the paper) that $F$ satisfies both conditions \eqref{eq:p2abs} and \eqref{eq:p2rel} of Problem~\ref{prob:two} for the full $P$. Since $\mathrm{w\text{-}err}_Z(h) = F(h)$, the coreset $Z$ realises the desired function $F$.
 
\begin{theorem}[Theorem 6 in the paper]\label{thm:coreset}
  Let $n$ and $w$ be the size and width of the input $P$, respectively. In
  \[
    O\!\left(\frac{w}{\varepsilon^2}\,\log\!\frac{n}{w}\cdot\log\frac{n}{\delta}\right)
  \]
  probes, we can obtain with probability at least $1 - \delta$ a relative-comparison coreset $Z$ of $P$ with
  \[
    |Z| = O\!\left(\frac{w}{\varepsilon^2}\,\log\!\frac{n}{w}\cdot\log\frac{n}{\delta}\right).
  \]
\end{theorem}
 
\subsubsection{Example (continued)}
 At the top level, $S_2$ is drawn from $P_{\mathrm{rest}} = \{1,2,5,6,7,8\}$ (size 6) and $S_\alpha$ from $P_\alpha = \{3\}$ (size 1). The recursion on $P_{\mathrm{mid}} = \{4\}$ (size 1) trivially probes the single element. With weights assigned proportionally to the set sizes, $\mathrm{w\text{-}err}_Z$ correctly scales the sampled errors back to represent all of $P$.
 
% ─────────────────────────────────────────────────────────────
\subsection{Extension to Higher Dimensions}
 
For $d > 1$, the algorithm first computes a \textbf{chain decomposition} $C_1, \ldots, C_w$ of $P$ using Dilworth's Theorem --- the same decomposition used in the cost analysis of RPE (Section~2). Since each chain $C_i$ is ordered, it can be treated as a 1D instance.
 
Applying the 1D coreset construction to each $C_i$ independently yields sub-coresets $Z_1, \ldots, Z_w$. The final coreset is $Z = \bigcup_{i=1}^{w} Z_i$. For every $h \in \Hmon$:
\[
  \mathrm{err}_P(h) = \sum_{i=1}^{w} \mathrm{err}_{C_i}(h), \qquad \mathrm{w\text{-}err}_Z(h) = \sum_{i=1}^{w} \mathrm{w\text{-}err}_{Z_i}(h).
\]
Since each $Z_i$ satisfies a per-chain relative bound with unknown shift $\Delta_i$, summing gives the global bound with $\Delta = \sum_i \Delta_i$.
 
% ─────────────────────────────────────────────────────────────
\subsection{Achieving the $(1+\varepsilon)$ Guarantee}

Given the coreset $Z$, finding the best monotone classifier requires \emph{no further probing}: simply compute
\[
  \hat{h} = \arg\min_{h\in\Hmon}\mathrm{w\text{-}err}_Z(h),
\]
which can be done in time polynomial in $|Z|$ and $d$.

\begin{corollary}[Corollary 7 in the paper]\label{cor:main}
  For Problem~1 with any $\varepsilon\in(0,1]$, there exists an algorithm that finds, with high probability, a monotone classifier with error at most $(1+\varepsilon)\kstar$ using
  \[
    O\!\left(\frac{w}{\varepsilon^2}\log\!\frac{n}{w}\cdot\log n\right)
  \]
  probes, where $n=|P|$, $w$ is the width of $P$, and $\kstar$ is the optimal monotone error.
\end{corollary}

The argument is direct: for any $h\in\Hmon$, the coreset bound gives
\[
  \mathrm{err}_P(\hat{h})\!\left(1-\tfrac\varepsilon4\right)
  \le \mathrm{w\text{-}err}_Z(\hat{h})-\Delta
  \le \mathrm{w\text{-}err}_Z(h^*)-\Delta
  \le \mathrm{err}_P(h^*)\!\left(1+\tfrac\varepsilon4\right),
\]
so setting $h=h^*$ (the true optimal) and rearranging yields $\mathrm{err}_P(\hat{h})\le(1+\varepsilon)\kstar$.

\medskip
\subsubsection{Example (conclusion)} We compute $\mathrm{w\text{-}err}_Z(h^\tau)$ for each threshold $\tau$. The minimiser is $h_{4.5}$ (equivalently $h_4$), with weighted error $\approx0$. Since $\kstar=0$, the $(1+\varepsilon)\kstar=0$ bound is met exactly.
  
\section{Full Algorithmic Description}
\begin{algorithm}
\caption{BuildCoreset($P$)}
\begin{algorithmic}[1]
\STATE $Z \gets \emptyset$
\IF{$|P| = 1$}
    \STATE Probe the (only) element $p \in P$
    \STATE $Z \gets \{p\}$ with $\text{weight}(p) = 1$
\ELSE
    \STATE Probe sample $S_1$ of size $O\!\left(\frac{1}{\varepsilon^2} \log\left(\frac{|P|\ell}{\delta}\right)\right)$ from $P$
    \STATE \COMMENT{Defines $G_1(h) = (|P|/|S_1|)\cdot \mathrm{err}_{S_1}(h)$; use $G_1$ to find $\alpha, \beta$ and split $P$ into $P_\alpha, P_{\text{mid}}, P_{\text{rest}}$}

    \IF{$P_{\text{rest}} \neq \emptyset$}
        \STATE Probe sample $S_2$ of size $O\!\left(\frac{1}{\varepsilon^2} \log\left(\frac{|P|\ell}{\delta}\right)\right)$ from $P_{\text{rest}}$
        \STATE \COMMENT{Defines $G_2(h) = (|P_{\text{rest}}|/|S_2|)\cdot \mathrm{err}_{S_2}(h)$}
        \STATE Add $S_2$ to $Z$ with $\text{weight}(p) = |P_{\text{rest}}|/|S_2|$ for each $p \in S_2$
    \ENDIF

    \IF{$P_\alpha \neq \emptyset$}
        \STATE Probe sample $S_\alpha$ of size $O\!\left(\frac{1}{\varepsilon^2} \log\left(\frac{|P|\ell}{\delta}\right)\right)$ from $P_\alpha$
        \STATE \COMMENT{Defines $F_\alpha(h) = (|P_\alpha|/|S_\alpha|)\cdot \mathrm{err}_{S_\alpha}(h)$}
        \STATE Add $S_\alpha$ to $Z$ with $\text{weight}(p) = |P_\alpha|/|S_\alpha|$ for each $p \in S_\alpha$
    \ENDIF

    \STATE $Z_{\text{mid}} \gets \textsc{BuildCoreset}(P_{\text{mid}})$
    \STATE Add $Z_{\text{mid}}$ to $Z$
\ENDIF

\STATE \textbf{return} $Z$
\end{algorithmic}
\end{algorithm}

\section{Proofs and Lower Bounds}
% ============================================================

Having established algorithms for monotone classification (RPE achieving $2\kstar$ in Section~2 and the coreset-based algorithm achieving $(1+\varepsilon)\kstar$ in Section~3), the natural question is: \emph{can we do better?} This section answers that question by proving \textbf{lower bounds} --- results showing that \emph{no algorithm} can substantially outperform the ones we have. Together with the upper bounds, these lower bounds establish that our algorithms are \textbf{near-optimal}.

We proceed in three stages, mirroring the three regimes of $\varepsilon$:
\begin{enumerate}
  \item \textbf{Exact case} ($\varepsilon = 0$): finding an optimal classifier requires $\Omega(n)$ probes (Theorem~\ref{thm:lb-exact}).
  \item \textbf{Constant approximation} ($\varepsilon$ is a constant): any $c$-approximate algorithm requires $\Omega(w \cdot \mathrm{Log}\,\frac{n}{(k^*+1)w})$ probes (Theorem~\ref{thm:lb-constant}).
  \item \textbf{Arbitrary $\varepsilon$}: any $(1+\varepsilon)$-approximate algorithm requires $\Omega(w/\varepsilon^2)$ probes (Theorem~\ref{thm:lb-arbitrary}).
\end{enumerate}

% ─────────────────────────────────────────────────────────────
\subsection{The Exact Case: $\varepsilon = 0$ Requires $\Omega(n)$ Probes}

When $\varepsilon = 0$, the algorithm must find an \emph{optimal} monotone classifier --- one that achieves exactly $\kstar$ errors. The following theorem shows this is essentially as hard as reading the entire input.

\begin{theorem}[Theorem 10 in the paper]\label{thm:lb-exact}
  For Problem~\ref{prob:main}, any algorithm that finds an optimal monotone classifier with probability greater than $2/3$ must probe $\Omega(n)$ elements in expectation. This holds even when:
  \begin{itemize}
    \item the dimensionality $d = 1$, and
    \item the algorithm knows $\kstar$ in advance.
  \end{itemize}
\end{theorem}

\begin{remark}[Significance]
This result justifies the entire study of the approximate case ($\varepsilon > 0$). If finding the exact optimum were cheap, there would be no need for approximation. The $\Omega(n)$ lower bound shows that \emph{even with strong prior knowledge} (knowing $\kstar$), no clever probing strategy can avoid reading nearly all of $P$.
\end{remark}

\subsubsection{The Hard Input Family}

The proof constructs a family $\mathcal{P}$ of $n$ one-dimensional inputs that any algorithm must distinguish between. All inputs share the same point locations $\{1, 2, \ldots, n\}$ and differ only in their label assignments.

\medskip
\noindent\textbf{Construction.} Group the $n$ elements into $n/2$ \emph{pairs}: $(1,2), (3,4), \ldots, (n-1, n)$. In a \emph{normal pair} $(2i-1, 2i)$, element $2i-1$ has label $+1$ and element $2i$ has label $-1$. Each input in $\mathcal{P}$ contains exactly one \emph{anomaly pair} where the normal labelling is violated:

\begin{itemize}
  \item \textbf{$(-1)$-input $P_{-1}(i)$}: The anomaly pair is $(2i-1, 2i)$ where \emph{both} elements receive label $-1$. That is, element $2i-1$ is flipped from $+1$ to $-1$.
  \item \textbf{$(+1)$-input $P_{+1}(i)$}: The anomaly pair is $(2i-1, 2i)$ where \emph{both} elements receive label $+1$. That is, element $2i$ is flipped from $-1$ to $+1$.
\end{itemize}

This gives $n/2$ choices for the anomaly pair and $2$ choices for its type, yielding $|\mathcal{P}| = n$ total inputs.

\begin{example}
  For $n = 6$, the elements are $\{1,2,3,4,5,6\}$ grouped into pairs $(1,2), (3,4), (5,6)$. In a normal pair, labels are $(+1, -1)$. Some inputs in $\mathcal{P}$:
  \begin{center}
  \begin{tabular}{lccccccl}
    \toprule
    Input & 1 & 2 & 3 & 4 & 5 & 6 & Anomaly \\
    \midrule
    $P_{-1}(1)$ & $\mathbf{-1}$ & $-1$ & $+1$ & $-1$ & $+1$ & $-1$ & pair 1 flipped to $(-1,-1)$ \\
    $P_{+1}(2)$ & $+1$ & $-1$ & $+1$ & $\mathbf{+1}$ & $+1$ & $-1$ & pair 2 flipped to $(+1,+1)$ \\
    $P_{-1}(3)$ & $+1$ & $-1$ & $+1$ & $-1$ & $\mathbf{-1}$ & $-1$ & pair 3 flipped to $(-1,-1)$ \\
    \bottomrule
  \end{tabular}
  \end{center}
  Bold entries mark the flipped element that creates the anomaly.
\end{example}

\subsubsection{Key Properties of the Family}

\begin{proposition}[Proposition 5 in the paper]\label{prop:no-shared-opt}
  For any $i \in [n/2]$, no monotone classifier can be optimal for \emph{both} $P_{-1}(i)$ and $P_{+1}(i)$.
\end{proposition}

\begin{proof}
  Every input in $\mathcal{P}$ has optimal monotone error $\kstar = n/2 - 1$. Every 1D monotone classifier has the form $h^\tau$ (mapping points $> \tau$ to $+1$). Consider the three cases for a classifier $h^\tau$:
  \begin{itemize}
    \item $\tau < 2i - 1$: On $P_{-1}(i)$, both elements $2i-1$ and $2i$ are labelled $-1$ but $h^\tau$ maps them to $+1$, giving error $n/2 + 1 > \kstar$.
    \item $\tau = 2i - 1$: On $P_{-1}(i)$, element $2i$ is labelled $-1$ but mapped to $+1$, giving error $n/2 > \kstar$.
    \item $\tau \geq 2i$: On $P_{+1}(i)$, both elements $2i-1$ and $2i$ are labelled $+1$ but $h^\tau$ maps them to $-1$, giving error $n/2 + 1 > \kstar$.
  \end{itemize}
  In every case, $h^\tau$ is suboptimal on at least one of $P_{-1}(i)$ or $P_{+1}(i)$.
\end{proof}

\begin{remark}[Intuition]
  The anomaly pair determines whether the optimal classifier should ``cut'' to the left or right of that pair. Without identifying which pair is anomalous \emph{and} what type it is, the algorithm cannot determine the correct cut point.
\end{remark}

\subsubsection{The Counting Argument (Lemma 11)}

To prove the lower bound, the paper first analyzes \emph{deterministic} algorithms, then extends to randomized ones via Yao's minimax theorem.

\medskip
\noindent\textbf{Free labels boost.} To make the lower bound stronger, we \emph{help} the algorithm: whenever it probes one element of a pair $(2i-1, 2i)$, we reveal the label of the other element for free. If the lower bound holds even with this advantage, it must hold without it. We say the algorithm ``probes pair $i$'' when it probes either $2i-1$ or $2i$.

\medskip
A deterministic algorithm $A_\mathrm{det}$ (with free labels) probes pairs in a fixed sequence $x_1, x_2, \ldots, x_t$. It stops when it discovers the anomaly pair (since all normal pairs look identical). If it reaches the end of the sequence without finding the anomaly, it outputs a fixed classifier $h_\mathrm{det}$.

\begin{lemma}[Lemma 11 in the paper]\label{lem:det-cost}
  Fix any deterministic algorithm $A_\mathrm{det}$ and constant $0 \le c < 1$. For $n \ge 4$: if $A_\mathrm{det}$ errs on at most $cn/2$ inputs in $\mathcal{P}$, then its total cost across all inputs in $\mathcal{P}$ (denoted $\mathrm{family\text{-}cost}$) satisfies:
  \[
    \mathrm{family\text{-}cost}(A_\mathrm{det}) \;\ge\; \frac{n^2(1 - c^2)}{4}.
  \]
\end{lemma}

\begin{proof}
  Define:
  \begin{align*}
    \mathrm{family\text{-}err}(A_\mathrm{det}) &= \text{number of inputs in } \mathcal{P} \text{ on which } A_\mathrm{det} \text{ fails to find an optimal classifier}, \\
    \mathrm{family\text{-}cost}(A_\mathrm{det}) &= \text{total number of probes across all inputs in } \mathcal{P}.
  \end{align*}

  \textbf{Step 1: Error counting.} For each $i \notin \{x_1, \ldots, x_t\}$, the algorithm never probes pair $i$, so it outputs the same classifier $h_\mathrm{det}$ on both $P_{-1}(i)$ and $P_{+1}(i)$. By Proposition~\ref{prop:no-shared-opt}, $h_\mathrm{det}$ must fail on at least one of them. Thus:
  \[
    \mathrm{family\text{-}err}(A_\mathrm{det}) \;\ge\; n/2 - t.
  \]

  \textbf{Step 2: Cost accounting.} For each $i \notin \{x_1, \ldots, x_t\}$, the algorithm probes all $t$ pairs on both $P_{-1}(i)$ and $P_{+1}(i)$, contributing $2t$ probes. For $i = x_j$ (i.e., the anomaly is found at position $j$), the algorithm probes $j$ pairs on each of $P_{-1}(x_j)$ and $P_{+1}(x_j)$, contributing $2j$ probes. Hence:
  \[
    \mathrm{family\text{-}cost}(A_\mathrm{det}) = 2t \cdot (n/2 - t) + 2\sum_{j=1}^{t} j = nt - t^2 + t.
  \]

  \textbf{Step 3: Combining.} If $\mathrm{family\text{-}err} \le cn/2$, then $t \ge n(1-c)/2$. For $t \in [n(1-c)/2, \; n/2]$:
  \[
    \mathrm{family\text{-}cost} \;\ge\; nt - t^2 \;\ge\; \frac{n^2(1 - c^2)}{4}. \qedhere
  \]
\end{proof}

\subsubsection{From Deterministic to Randomized (Corollary 12)}

\begin{corollary}[Corollary 12 in the paper]\label{cor:randomized-lb}
  For $n \ge 4$, any randomized algorithm $A$ with $\mathrm{family\text{-}err}(A) < n/3$ satisfies $\E[\mathrm{family\text{-}cost}(A)] = \Omega(n^2)$.
\end{corollary}

\begin{proof}
  A randomized algorithm is a distribution over deterministic algorithms. Call a deterministic algorithm $A_\mathrm{det}$ \emph{accurate} if $\mathrm{family\text{-}err}(A_\mathrm{det}) \le 2n/5$.

  \textbf{Claim:} $\Pr[A \in A_\mathrm{acc}] > 1/6$. Otherwise, $\Pr[A \notin A_\mathrm{acc}] \ge 5/6$, and since inaccurate algorithms err on $> 2n/5$ inputs:
  \[
    \mathrm{family\text{-}err}(A) \;\ge\; \frac{2n}{5} \cdot \Pr[A \notin A_\mathrm{acc}] \;\ge\; \frac{2n}{5} \cdot \frac{5}{6} = \frac{n}{3},
  \]
  contradicting $\mathrm{family\text{-}err}(A) < n/3$.

  By Lemma~\ref{lem:det-cost} with $c = 4/5$, every accurate algorithm has $\mathrm{family\text{-}cost} = \Omega(n^2)$, so:
  \[
    \E[\mathrm{family\text{-}cost}(A)] \;\ge\; \Omega(n^2) \cdot \Pr[A \in A_\mathrm{acc}] = \Omega(n^2).
  \]
\end{proof}

\begin{remark}[How the Corollary implies Theorem~\ref{thm:lb-exact}]
  If algorithm $A$ finds an optimal classifier with probability $> 2/3$ on \emph{every} input, then $\mathrm{family\text{-}err}(A) < |\mathcal{P}|/3 = n/3$. By Corollary~\ref{cor:randomized-lb}, $\E[\mathrm{family\text{-}cost}(A)] = \Omega(n^2)$. Since $|\mathcal{P}| = n$, by an averaging argument at least one input in $\mathcal{P}$ requires $\Omega(n)$ expected probes.
\end{remark}

\begin{remark}[Yao's Minimax Theorem]
  The proof technique follows a standard pattern in computational complexity:
  \begin{enumerate}
    \item Construct a hard family of inputs.
    \item Prove a lower bound on deterministic algorithms averaged over this family.
    \item Apply Yao's minimax theorem: any randomized algorithm that succeeds on all inputs with high probability must also incur high cost on the hard family.
  \end{enumerate}
  This is a game-theoretic argument --- the ``adversary'' (who picks the input) and the ``algorithm'' (who picks the probing strategy) cannot both win cheaply.
\end{remark}

\subsection{Lower Bound for Constant Approximation Ratios}\label{sec:lb-constant}

Having shown that exact optimality is expensive, we now ask: does allowing a constant approximation ratio (e.g., $c = 2$ or $c = 10$) significantly reduce the cost? The answer is: it helps, but there is still a non-trivial lower bound that scales with the \emph{width} $w$.

\begin{theorem}[Theorem 13 in the paper]\label{thm:lb-constant}
  Let $n', w', k, c$ be arbitrary integers satisfying $n' \ge 2, w' \ge 1, k \ge 0, c \ge 1$, and $n'$ is a multiple of $w'$. Set $n = n' + 2k + 2ckn'$ and $w = w' + \mathbf{1}_{k \ge 1}$. For Problem~\ref{prob:main}, there exists a family $\mathcal{P}$ of inputs with size $n$, width $w$, and optimal monotone error $\kstar = k$ such that any randomized algorithm guaranteeing an expected error $\le c \cdot \kstar$ must probe $\Omega(w' \cdot \mathrm{Log}\,\frac{n'}{w'})$ elements in expectation on at least one input.
\end{theorem}

\begin{remark}[Special cases]
  \leavevmode
  \begin{itemize}
    \item \textbf{Realizable case} ($k = 0$): The theorem gives a lower bound of $\Omega(w \cdot \mathrm{Log}\,\frac{n}{w})$, matching the RPE upper bound up to constants.
    \item \textbf{Non-realizable case} ($k \ge 1$): Using $n'/w' \ge n/(4ckw)$, the lower bound becomes $\Omega(w \cdot \mathrm{Log}\,\frac{n}{\kstar w})$.
  \end{itemize}
\end{remark}

\subsubsection{Proof Strategy}

The proof proceeds in two stages.

\medskip
\noindent\textbf{Stage 1: The realizable case ($k = 0$).} We construct a hard family using $w'$ mutually independent boxes in $\R^2$. Each box contains $n'/w'$ points on its main diagonal. Labels are assigned independently per box: for each box, we choose one of $1 + n'/w'$ possible label assignments (specifying how many bottom points get label $-1$). This yields a family of $(1 + n'/w')^{w'}$ inputs.

Since any algorithm that always finds an optimal classifier must distinguish all these inputs, its decision tree must have at least $(1 + n'/w')^{w'}$ leaves. A binary tree with that many leaves has average depth $\Omega(w' \cdot \mathrm{Log}\,\frac{n'}{w'})$, establishing the lower bound for deterministic algorithms. Yao's minimax theorem extends it to randomized ones.

\medskip
\noindent\textbf{Stage 2: Reduction from non-realizable to realizable.} For $k \ge 1$, we ``pad'' each realizable input with \emph{dummy points} to create a non-realizable instance with $\kstar = k$.

\begin{definition}[Dummy Points Construction]
  Given a realizable input $P'$ with $w'$ boxes:
  \begin{enumerate}
    \item For each box $B_i$ and each pair of consecutive points $p_j, p_{j+1}$ in $B_i$:
    \begin{itemize}
      \item If $\mathrm{label}(p_j) = \mathrm{label}(p_{j+1})$: insert $2ck$ dummy points with the same label.
      \item If $\mathrm{label}(p_j) = -1$ and $\mathrm{label}(p_{j+1}) = +1$ (label transition): insert $ck$ dummies with label $-1$ and $ck$ dummies with label $+1$.
    \end{itemize}
    \item Add a \emph{dummy box} independent from all others, containing $2k$ points: the bottom $k$ have label $+1$ and the top $k$ have label $-1$ (deliberately reversed to force $k$ errors).
  \end{enumerate}
\end{definition}

\begin{proposition}[Properties of the padded input]
  The padded input $P$ satisfies:
  \begin{enumerate}
    \item $|P| = n' + 2k + 2ckn'$.
    \item $w = w' + 1$ (the dummy box adds one to the width).
    \item $\kstar = k$ (any monotone classifier must misclassify at least $k$ points in the dummy box; error $k$ is achievable by classifying all non-dummy points correctly).
  \end{enumerate}
\end{proposition}

The key insight is the following:

\begin{lemma}[Dummy points force correctness]
  If algorithm $A$ guarantees error $\le c \cdot \kstar = ck$ on the padded input $P$, then $A$ must correctly classify \emph{every non-dummy point} in $P$.
\end{lemma}

\begin{proof}
  Suppose the classifier $h$ output by $A$ misclassifies some non-dummy point $p$. Without loss of generality, suppose $\mathrm{label}(p) = -1$ but $h(p) = +1$. By construction, $p$ is dominated by at least $ck$ dummy points that also have label $-1$. Since $h$ is monotone and maps $p$ to $+1$, it must also map all points dominating $p$ to $+1$, misclassifying at least $ck$ dummy points. Adding $p$ itself, $\mathrm{err}_P(h) \ge ck + 1 > c\kstar$, violating the guarantee.
\end{proof}

Since the algorithm must correctly classify all non-dummy points, it effectively solves the realizable problem on the original $P'$. Therefore, the $\Omega(w' \cdot \mathrm{Log}\,\frac{n'}{w'})$ lower bound from Stage 1 carries over.

\begin{example}
  Consider $w' = 3$ boxes with $n'/w' = 4$ points each ($n' = 12$), and $k = 2, c = 3$.
  \begin{itemize}
    \item Each gap between consecutive points gets $2ck = 12$ dummy points.
    \item A dummy box gets $2k = 4$ points (top 2 labelled $-1$, bottom 2 labelled $+1$).
    \item Total: $n = 12 + 4 + 2 \cdot 3 \cdot 2 \cdot 12 = 12 + 4 + 144 = 160$.
    \item If the algorithm misclassifies any original point $p$, it also misclassifies $\ge ck = 6$ dummy neighbours, so $\mathrm{err} \ge 7 > ck = 6$. Thus $p$ must be classified correctly.
  \end{itemize}
\end{example}

\subsection{Lower Bound for Arbitrary $\varepsilon$}\label{sec:lb-arbitrary}

The previous lower bounds address the exact case and constant approximation ratios. The final result establishes a lower bound for \emph{any} $\varepsilon > 0$, showing that the $1/\varepsilon^2$ dependence in the coreset algorithm is unavoidable.

\begin{theorem}[Theorem 14 in the paper]\label{thm:lb-arbitrary}
  Let $0 < \varepsilon \le 1/10$. Fix integers $n \ge 1$ and $w \ge 1$ such that $n$ is a multiple of $w$ and $n \ge \frac{w \ln n}{\varepsilon^2}$. Any algorithm for Problem~\ref{prob:main} under $d = 2$ that guarantees expected error $(1+\varepsilon)\kstar$ must probe $\Omega(w/\varepsilon^2)$ elements in expectation on at least one input with width $w$.
\end{theorem}

\begin{remark}
  This is arguably the most technically demanding result in the paper. The proof uses techniques from \emph{hypothesis testing} --- specifically, the difficulty of distinguishing two slightly different coin biases from a limited number of samples.
\end{remark}

\subsubsection{The Hard Input}

Fix $w$ distinct locations $x_1, \ldots, x_w \in \R^2$ such that no location dominates another (width $w$). Place $n/w$ points at each location, each with a distinct ID.

\begin{definition}[Random labelling]
  Define:
  \[
    \gamma = 9\varepsilon, \qquad \mu_1 = \frac{1-\gamma}{2}, \qquad \mu_2 = \frac{1+\gamma}{2}.
  \]
  Each location $x_i$ is independently assigned a bias $\mu[i] \in \{\mu_1, \mu_2\}$ uniformly at random. Then each point at location $x_i$ receives label $+1$ with probability $\mu[i]$ and label $-1$ with probability $1 - \mu[i]$, independently.
\end{definition}

\begin{remark}[Intuition]
  At each location, the ``majority label'' is determined by whether $\mu[i] = \mu_2$ (majority $+1$) or $\mu[i] = \mu_1$ (majority $-1$). The optimal classifier maps $x_i$ to the majority label. The algorithm needs to \emph{infer the majority} at each location, which requires distinguishing $\mu_1$ from $\mu_2$ --- two values that differ by only $\gamma = 9\varepsilon$.
\end{remark}

\subsubsection{The Two Random Processes}

The proof introduces two random processes that generate the same distribution over outcomes but differ in \emph{when} labels are assigned.

\medskip
\noindent\textbf{RP-1 (All labels upfront):}
\begin{enumerate}
  \item Sample $\mu \in \{\mu_1, \mu_2\}^w$ uniformly at random.
  \item Label \emph{every} point at $x_i$ with $\Pr[+1] = \mu[i]$.
  \item Run algorithm $A$ on the labelled $P$.
  \item Measure $R_1 = \mathrm{err}_P(h_A) / \kstar$.
\end{enumerate}

\noindent\textbf{RP-2 (Labels on demand):}
\begin{enumerate}
  \item Sample $\mu \in \{\mu_1, \mu_2\}^w$ uniformly at random.
  \item When $A$ probes a point $p$ at $x_i$, assign its label with $\Pr[+1] = \mu[i]$.
  \item After $A$ finishes, label all remaining (un-probed) points.
  \item Measure $R_2 = \mathrm{err}_P(h_A) / \kstar$.
\end{enumerate}

\begin{lemma}[Lemma 15 in the paper]\label{lem:rp-equiv}
  $\E[R_1] = \E[R_2]$ and $\E[\Lambda_1] = \E[\Lambda_2]$, where $\Lambda_j$ is the number of probes in RP-$j$.
\end{lemma}

\begin{proof}[Proof sketch]
  Both processes assign labels from the same distribution. The only difference is timing: RP-1 assigns all labels before the algorithm runs, RP-2 assigns them as needed. Since the algorithm's decisions depend only on the labels it has \emph{seen} (not unseen ones), the distribution of all observable quantities --- including the algorithm's output and cost --- is identical.
\end{proof}

\begin{remark}
  The purpose of RP-2 is to make the analysis cleaner. In RP-2, we can reason about what the algorithm ``knows'' after probing: it has seen some labels at each location and must infer $\mu[i]$ from them. This connects to the classical problem of distinguishing two coin biases.
\end{remark}

\subsubsection{The Distinguishing Barrier}

The heart of the lower bound is the following result from statistical learning theory.

\begin{lemma}[Lemma 17; Anthony--Bartlett]\label{lem:distinguish}
  Let $\mu$ be a random variable that equals $\mu_1$ or $\mu_2$ each with probability $1/2$. Let $\Sigma = (X_1, \ldots, X_m)$ be a sequence of i.i.d.\ samples with $\Pr[X_i = 1] = \mu$ and $\Pr[X_i = -1] = 1 - \mu$. If $m < M$ where
  \[
    M = \frac{\ln(9/8) \cdot (1 - \gamma^2)}{\gamma^2},
  \]
  then no algorithm can correctly infer $\mu$ from $\Sigma$ with probability greater than $2/3$.
\end{lemma}

\begin{remark}
  Since $\gamma = 9\varepsilon$, we have $M = \Theta(1/\varepsilon^2)$. This means that distinguishing $\mu_1$ from $\mu_2$ at a single location requires $\Theta(1/\varepsilon^2)$ samples. This is the fundamental bottleneck.
\end{remark}

\subsubsection{Light and Heavy Locations}

We say location $i$ is \emph{light} if $\Pr[A \text{ probes fewer than } M \text{ points at } x_i] \ge 3/4$, and \emph{heavy} otherwise.

\begin{lemma}[Lemma 18 in the paper]\label{lem:light}
  If $\E[\Lambda_2] \le wM/8$, then more than $w/2$ locations are light.
\end{lemma}

\begin{proof}
  For each heavy location $i$, $\Pr[\text{probes at } x_i \ge M] > 1/4$, so $\E[\text{probes at } x_i] > M/4$. If $\ge w/2$ locations were heavy, the total expected probes would exceed $(w/2)(M/4) = wM/8$, contradicting the budget $\E[\Lambda_2] \le wM/8$.
\end{proof}

\begin{lemma}[Lemma 19 in the paper]\label{lem:wrong-guess}
  If location $i$ is light, then the algorithm's classifier ``guesses wrong'' at $x_i$ (i.e., maps $x_i$ to the minority label) with probability $> 1/4$.
\end{lemma}

\begin{proof}
  By Lemma~\ref{lem:distinguish}, when fewer than $M$ samples are seen at $x_i$, the algorithm cannot infer $\mu[i]$ with probability $> 2/3$. It guesses wrong with probability $> 1/3$. Since $i$ is light (fewer than $M$ samples with probability $\ge 3/4$):
  \[
    \Pr[\text{wrong guess}] \;\ge\; \Pr[\text{wrong} \mid \text{few samples}] \cdot \Pr[\text{few samples}] > \frac{1}{3} \cdot \frac{3}{4} = \frac{1}{4}. \qedhere
  \]
\end{proof}

\subsubsection{Completing the Proof}

Each wrong guess at location $x_i$ causes the classifier to misclassify the majority at that location, adding excess error of at least $n\gamma/(2w)$. With more than $w/2$ light locations and each contributing excess error with probability $> 1/4$:

\[
  \E[\text{excess error}] \;\ge\; \frac{w}{2} \cdot \frac{1}{4} \cdot \frac{n\gamma}{2w} = \frac{n\gamma}{16}.
\]

The optimal error is $\kstar \le n(1/2 - \gamma/4)$, so the expected approximation ratio satisfies:

\[
  \E[R_2] \;\ge\; 1 + \frac{n\gamma/16}{n(1/2 - \gamma/4)} > 1 + \frac{153}{144}\varepsilon > 1 + \varepsilon.
\]

By Lemma~\ref{lem:rp-equiv}, $\E[R_1] = \E[R_2] > 1 + \varepsilon$, meaning the algorithm with budget $\le wM/8 = \Theta(w/\varepsilon^2)$ cannot guarantee expected error $(1+\varepsilon)\kstar$.

\begin{remark}[The role of the Chernoff bound]
  The proof also uses a Chernoff bound (Lemma 20 in the paper) to show that, with high probability, the labelled set $P$ is ``intended'' --- meaning each location has close to the expected number of majority-label points. This ensures that $\kstar$ is well-behaved and the excess error from wrong guesses is reliably large.
\end{remark}

\subsection{Near-Optimality of the Algorithms}\label{sec:near-optimality}

With both upper and lower bounds in hand, we can now compare them side by side. The following table summarizes the results:

\begin{table}[ht]
\centering
\caption{Matching upper and lower bounds for Problem~\ref{prob:main}}
\begin{tabular}{llll}
\toprule
\textbf{Regime} & \textbf{Upper Bound} & \textbf{Lower Bound} & \textbf{Gap} \\
\midrule
$\varepsilon = 0$ & $O(n)$ & $\Omega(n)$ \scriptsize{[Thm~\ref{thm:lb-exact}]} & \textbf{Tight} \\
constant $c > 1$ & $O(w \cdot \mathrm{Log}\,\frac{n}{w})$ \scriptsize{[RPE]} & $\Omega(w \cdot \mathrm{Log}\,\frac{n}{(\kstar\!+\!1)w})$ \scriptsize{[Thm~\ref{thm:lb-constant}]} & Tight$^*$ \\
any $\varepsilon > 0$ & $O\!\left(\frac{w}{\varepsilon^2} \mathrm{Log}\,\frac{n}{w} \cdot \log n\right)$ \scriptsize{[Cor~\ref{cor:main}]} & $\Omega(w/\varepsilon^2)$ \scriptsize{[Thm~\ref{thm:lb-arbitrary}]} & $O(\mathrm{Log} \cdot \log)$ \\
\bottomrule
\end{tabular}
\end{table}
\noindent {\small $^*$Tight when $\kstar \le (n/w)^{1-\delta}$ for any small constant $\delta > 0$.}

\medskip
Several conclusions emerge:

\begin{enumerate}
  \item \textbf{$\varepsilon = 0$ is hopeless.} The $\Omega(n)$ lower bound matches the trivial $O(n)$ upper bound (probe everything). No algorithm can do better.

  \item \textbf{Width $w$ is the correct complexity parameter.} Both upper and lower bounds scale with $w$, confirming that the \emph{dominance width} --- not $n$ or $d$ --- captures the intrinsic difficulty of monotone classification. This is a key structural insight of the paper.

  \item \textbf{The $1/\varepsilon^2$ dependence is necessary.} The $\Omega(w/\varepsilon^2)$ lower bound shows that the quadratic dependence on $1/\varepsilon$ in the coreset algorithm is not an artifact of the proof technique --- it is a fundamental requirement. Halving $\varepsilon$ quadruples the cost.

  \item \textbf{Only a polylogarithmic gap remains.} The gap between the upper bound $O(w/\varepsilon^2 \cdot \mathrm{Log}(n/w) \cdot \log n)$ and the lower bound $\Omega(w/\varepsilon^2)$ is a factor of $O(\mathrm{Log}(n/w) \cdot \log n)$. Closing this gap --- from either direction --- remains an open problem.
\end{enumerate}

\begin{remark}[The ``true'' complexity]
  The paper concludes that the true complexity of Problem~\ref{prob:main} is $\Theta(w/\varepsilon^2)$ up to polylogarithmic factors. This is a strong characterization: regardless of the input distribution, dimensionality, or value of $\kstar$, the cost is essentially determined by $w$ and $\varepsilon$ alone.
\end{remark}

\subsection{Mathematical Machinery (Supplementary)}\label{sec:math-machinery}

This section collects the key mathematical tools used in the lower bound proofs. These are not specific to monotone classification --- they are general-purpose techniques from combinatorics, probability, and learning theory.

\subsubsection{Concentration Bounds (Chernoff Bounds)}

Chernoff bounds quantify how closely the average of independent random variables approximates its expectation. They are used throughout the paper for sample-based estimation.

\begin{lemma}[Chernoff bounds]
  Let $X_1, \ldots, X_t$ be independent Bernoulli random variables with $\Pr[X_i = 1] = \mu$.
  \begin{itemize}
    \item \textbf{Multiplicative form:} For any $\gamma \in (0, 1]$:
    \[
      \Pr\!\left[\left|\mu - \frac{1}{t}\sum_{i=1}^t X_i\right| \ge \gamma\mu\right] \;\le\; 2\exp\!\left(-\frac{\gamma^2 t\mu}{3}\right).
    \]
    \item \textbf{Upper tail:} For any $\gamma \ge 0$:
    \[
      \Pr\!\left[\frac{1}{t}\sum_{i=1}^t X_i \ge (1+\gamma)\mu\right] \;\le\; \exp\!\left(-\frac{\gamma^2}{2+\gamma} \cdot t\mu\right).
    \]
  \end{itemize}
\end{lemma}

\begin{remark}[Application in this paper]
  Chernoff bounds are used in two ways:
  \begin{enumerate}
    \item \textbf{Coreset construction} (Section~3): to ensure that $G_1, G_2, F_\alpha$ approximate the true error with high probability. The sample size $O(1/\varepsilon^2 \cdot \log(n/\delta))$ comes directly from inverting the Chernoff bound.
    \item \textbf{Lower bound for arbitrary $\varepsilon$} (Theorem~\ref{thm:lb-arbitrary}): to show that the labelled set is ``intended'' with high probability (Lemma 20 in the paper).
  \end{enumerate}
\end{remark}

\subsubsection{Yao's Minimax Theorem}

\begin{theorem}[Yao's Minimax Theorem]
  Let $\mathcal{P}$ be a distribution over inputs. If every deterministic algorithm has expected cost at least $C$ on inputs drawn from $\mathcal{P}$, then every randomized algorithm has expected cost at least $C$ on some (worst-case) input.
\end{theorem}

\begin{remark}
  Yao's theorem converts an \emph{average-case lower bound for deterministic algorithms} into a \emph{worst-case lower bound for randomized algorithms}. It is a fundamental tool in complexity theory, used here in both the $\varepsilon = 0$ proof (Theorem~\ref{thm:lb-exact}) and the constant-ratio proof (Theorem~\ref{thm:lb-constant}).
\end{remark}

\subsubsection{VC-Dimension and Related Quantities}

The paper proves in Appendix~B that several standard complexity measures of the hypothesis class $\Hmon$ are all $\Omega(w)$:

\begin{definition}[VC-dimension]
  The \textbf{VC-dimension} $\lambda$ of $\Hmon$ on $P$ is the size of the largest subset $S \subseteq P$ that can be \emph{shattered} by $\Hmon$: for every labelling $f : S \to \{-1, +1\}$, there exists $h \in \Hmon$ with $h(p) = f(p)$ for all $p \in S$.
\end{definition}

\begin{proposition}[VC-dimension lower bound]
  The VC-dimension of $\Hmon$ on $P$ is at least $w$ (the width of $P$).
\end{proposition}

\begin{proof}
  Let $p_1, \ldots, p_w$ be $w$ pairwise incomparable points in $P$ (guaranteed by Dilworth's theorem). For any labelling $f$, define $h \in \Hmon$ by: if $f(p_i) = +1$, set $h(q) = +1$ for all $q \succeq p_i$; if $f(p_i) = -1$, set $h(q) = -1$ for all $q \preceq p_i$. Since the $p_i$ are pairwise incomparable, these constraints are consistent, so $\{p_1, \ldots, p_w\}$ is shattered.
\end{proof}

The paper similarly shows that the \textbf{disagreement coefficient} $\theta$, the \textbf{star number} $s$, and the \textbf{teaching dimension} $\chi$ of $\Hmon$ are all $\Omega(w)$ in the worst case. This is significant because:
\begin{itemize}
  \item Existing active learning algorithms have costs that depend on these quantities (see bounds (5) and (6) in Section 1.3 of the paper).
  \item Since all four measures are $\Omega(w)$, the best cost achievable by prior methods is at least $\Omega(w^2/\varepsilon^2)$ or $\Omega(w + n \cdot w / (\varepsilon \kstar))$, which is \emph{worse} than the $O(w/\varepsilon^2 \cdot \mathrm{Log}(n/w) \cdot \log n)$ achieved by the coreset algorithm.
\end{itemize}

This establishes that the algorithms in this paper strictly improve over the state of the art in active learning for monotone classification.
